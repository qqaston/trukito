# Trukito 🃏

Un juego de **truco** estilo arcade escrito en **C**.

Es un proyecto personal que arranqué para practicar C. La idea era armar un truco con onda arcade, pero **no lo terminé**, así que está incompleto y puede tener cosas rotas.

## Estructura

```
trukito/
├── dat/        # datos del juego
├── include/    # headers (.h)
├── src/        # código fuente (.c)
├── main.c      # punto de entrada
└── Makefile
```

## Compilar y ejecutar

Necesitás `gcc` (o similar) y `make`.

```bash
git clone https://github.com/qqaston/trukito.git
cd trukito
make
./trukito   # el nombre del ejecutable puede variar, mirá el Makefile
```

## Objetivo

Practicar C: manejo de memoria, estructuras, organización de un proyecto en varios archivos y uso de Makefile.
